# 🌐 Cisco Networks Basics

ده الريبو اللي ببدأ فيه رحلتي في **تعلم شبكات الحاسوب (Computer Networking)**.

هبدأ من الأساسيات مع **Cisco Networking Academy**، وهطبق اللي بتعلمه باستخدام **Cisco Packet Tracer**.

الهدف من الريبو ده إني أبني أساس كويس في الشبكات وأفهم فعلًا إزاي الأجهزة بتتواصل مع بعض وإزاي البيانات بتتحرك جوه الشبكة، بدل ما أكون بحفظ تعريفات وخلاص.

---

## 🎯 ليه بتعلم Networking؟

لأن الشبكات جزء أساسي جدًا من طريق **Cybersecurity**.

قبل ما أتعلم إزاي أحمي شبكة أو أكتشف هجوم عليها، محتاجة الأول أفهم هي أصلًا شغالة إزاي.

فخلال الرحلة دي هدفي أفهم:

* الأجهزة بتتواصل مع بعض إزاي؟
* البيانات بتتنقل من جهاز لجهاز إزاي؟
* الـ IP Address والـ MAC Address بيعملوا إيه؟
* الـ Router والـ Switch وظيفتهم إيه؟
* الـ Protocols بتستخدم ليه؟
* الشبكة بتتكون وبتتنظم إزاي؟
* لو حصلت مشكلة في الاتصال، أقدر أحدد سببها إزاي؟

## 🧪 مش هتعلم نظري بس

جنب المذاكرة النظرية، هستخدم **Cisco Packet Tracer** علشان أجرب وأطبق اللي بتعلمه عمليًا.

يعني الطريقة اللي بحاول أمشي بيها هي:

**أتعلم → أفهم → أطبق → أجرب → أغلط → أحل المشكلة → أوثق اللي اتعلمته**

لأن الفكرة مش إني أعرف معنى المصطلح وقت المذاكرة وبعدين أنساه بعد ما أقفل اللابتوب.
عاوزة أوصل لمرحلة أقدر فيها أفهم الشبكة وأتعامل معاها فعليًا.
